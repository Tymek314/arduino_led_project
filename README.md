# arduino_led_project
Download all of the files and put them into one folder

Run main.py to start webpage

Make sure you have PlatformIO downloaded for VSCode

Modify the definitions in main.cpp to what you need


For wiring and overall physical setup instructions follow WLED's setup instructions:

https://kno.wled.ge/basics/wiring-guides/



Future additions (hopefully):

More effects

Idle effects

Bluetooth?



This project used ChatGPT to teach me how to control LED's, send signals to an arduino, and how to pull audio data from windows.
